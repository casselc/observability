# Quint model checks as traceability records (ci/trace/trace.py model).
#   jobs | script | name | regex over the script's report lines | technique | ids
# After a script runs, `trace.py model --script <script> --report <its report>` writes one record
# per entry: passed when every matching line has the result it expects (`sim ... X (expect X)`,
# `runs ... passed N>0 failed 0`), skipped when a random simulation did not reach an expected
# violation (an unknown), failed otherwise. No matching line, no record: the check reports it unrun.
# The deterministic scripted runs (*BreaksTest) are the evidence for a mutant; random `sim` mutant
# lines are not listed, since a miss there is not a failure (ci/model-check.sh warns).
